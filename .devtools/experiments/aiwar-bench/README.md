# aiwar-bench

**Question:** what does a change cost or gain the AI war, measured on the same fight: native
foundation against the Lua twins, NPC soldiers against bot players, before against after, and how
much the soldiers actually fight.

| Script | Runs |
|---|---|
| `aiwar_bench.py` | One saved fight replayed under each condition (docs/wartactics-engine-plan.md §4.4) |
| `aiwar_ab_bench.py` | Alternating A/B legs on one map and settings |
| `aiwar_fight_watch.py` | How much the soldiers fight over a span of the war |

Results: `results/` (ignored by git). Status: open.
